# Zeki's Portfolio

A personal portfolio website presenting Zeki's background, education, skills, projects, achievements, and contact information.

## Run locally

Open `index.html` in a web browser. The site uses plain HTML, CSS, and JavaScript and does not require a build step.

## Project files

- `index.html` - page content and structure
- `style.css` - layout, styling, and responsive design
- `script.js` - interactive behavior
- `images/` - portfolio images

## Customize

- Update the text and social links in `index.html`.
- Replace the image files in `images/` and update their paths in `index.html` if needed.
- Adjust colors, layout, and typography in `style.css`.
